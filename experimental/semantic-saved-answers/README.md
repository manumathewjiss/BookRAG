# Semantic Saved Answers research archive

This directory preserves the local semantic-matching prototype, evaluation design, simulated results, and draft migrations. It is **not** part of the running BookRAG API and has not been deployed. The live product uses strict saved-answer matching.

The benchmark results here use an offline simulated verifier. They do not establish live-model accuracy. Migrations `005` and `006` are research artifacts and must not be applied to production as part of the strict saved-answer release.
